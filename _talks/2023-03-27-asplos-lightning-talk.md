This talk presents our paper *"Transparent Runtime Change Handling for Android Apps"* at ASPLOS 2023. The talk introduces **RCHDroid**, a transparent system-level solution that automatically handles runtime configuration changes in Android apps, eliminating common lifecycle management bugs without requiring developer intervention. It demonstrates the core ideas, experimental results, and implications for improving Android system reliability and responsiveness. The presentation took place on Day 1 (March 27) of the conference in the Session 1C: IoT/Embedded/Mobile.
